# Provenance — EV-pack end-of-line cell

Everything in this directory is **synthetic**, written for this repository and licensed Apache-2.0 with it.
No customer files, no manufacturer data, and no copied manual text. Physical values are representative.

| File | Kind | How it was made |
|---|---|---|
| `narrative.md` | synthetic | Hand-written control narrative. Deliberately stale in one place (§4.4). |
| `io_list.csv` / `io_list.xlsx` | synthetic / derived | Tags written from scratch in an ISA-5.1 *style* (the standard itself is not reproduced). The xlsx is generated by `scripts/build_data.py`. |
| `parameters.csv` (Parameters sheet) | synthetic | Authoritative parameter values. |
| `cause_effect.csv` / `cause_effect.xlsx` | synthetic / derived | C&E list; the xlsx grid is generated. |
| `st10/legacy.il`, `st20/legacy.il` | derived | Generated from the sealed reference programs plus the seeded defects, with documentation stripped. |
| `st30/program.il` | synthetic | Hand-written. |
| `st*/device_comments.csv` | derived | Partial device comments, as a legacy project would have. |
| `gxw3/*.csv` | derived | Generated **by this harness** in the GX Works3 listed-instruction and device-comment CSV formats described in the GX Works3 Operating Manual SH(NA)-081215ENG §6.3 / §6.8. Not exported from GX Works3; import into GX Works3 is **unverified**. |
| `scenarios/st*.yaml` | synthetic | Factory-acceptance scenarios written from the narrative and parameter sheet. |
| `scenarios/ce_bindings.yaml` | synthetic | Engineer-authored bindings that turn each C&E row into a test. |
| `scenarios/ce_*.yaml` | derived | Generated from the C&E matrix + bindings. |
